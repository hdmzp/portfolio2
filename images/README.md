## 파일 추가·교체 규칙

- 이름을 바꾸려면 `assets/data.js` 의 `src` 값도 함께 고쳐 주세요.
- 새 캡처는 **가로 1500px 이하, 장당 400KB 이하**를 권장합니다.
- 카드 이미지 영역은 가로가 살짝 긴 비율이라, 세로로 아주 긴 캡처는 작게 보입니다.
